# 尸潮之夜 · NIGHT OF THE HORDE

俯视角的波次生存射击。广场上的路灯还亮着，你只有一支手电、一把枪和一片开阔地，尸潮从四面八方涌上来，撑过一波，就有一次采购的机会。单文件、零依赖、零外部请求：画面全部用 Canvas 手绘，音乐音效由 Web Audio 实时合成，仓库里没有任何图片或音频素材。

**在线试玩：** https://leslie06.github.io/zombie/

## 玩法

| 按键 | 作用 |
| --- | --- |
| `W` `A` `S` `D` | 移动（八方向） |
| `鼠标` | 瞄准，**按住左键**持续射击 |
| `R` | 换弹（打空会自动换） |
| `Q` / `1`-`5` | 换枪 |
| `SHIFT` / `SPACE` | 冲刺翻滚，起步的一瞬间无敌 |
| `G` | 扔手雷 |
| `P` | 暂停 |
| `ENTER` | 商店里开始下一波；死了从头再来 |

打开后**先点一下画面**，键盘和声音才会生效。

手机上是双摇杆，**推荐横屏玩**：

- **左半屏**按下即出现移动摇杆，**右半屏**的摇杆负责瞄准，推出去就自动开火 —— 摇杆的圈画在页面上而不是画布里，手指按哪儿它就长在哪儿
- 右下角四个圆键：换弹 / 换枪 / 手雷 / 冲刺
- **竖屏**时画面贴在顶部，下面那片空白照样是拇指区，左移动右瞄准

## 夜里只看得见一小块

场地是全黑的，你能看见的只有三样东西：脚下一圈微光、手电照出的那道光锥、四盏路灯下的光池。枪口的火光和爆炸会把周围照亮一瞬间。

黑暗里的僵尸只剩一对红眼睛 —— 这是有意留的活路，眼睛能看见，身体看不清。跑出画面的敌人会在屏幕边缘留一个红色小箭头，尸王的箭头更亮。

血、碎肉和尸体会永久留在地上，一局打到后半段，广场基本是踩着尸体走。

## 六种僵尸

| 名字 | 特点 |
| --- | --- |
| 行尸 | 慢，多，成群 |
| 疾行者 | 跑得比你快，血薄，专挑你换弹的时候到 |
| 吐酸者 | 远远吐绿色酸液，会拉开距离，优先点掉 |
| 胖子 | 死了炸开一大团毒雾，贴上来会自爆；离远了打 |
| 壮尸 | 厚血高伤，几乎打不退 |
| 尸王 | 每 5 波来一只（最多同时三只）。会蓄力冲锋，掉到一半血会暴走并召来疾行者 |

僵尸不会寻路，只会朝你直走，但会探路绕开挡在面前的车和墙 —— 所以掩体能拖住它们，但拖不住太久。

## 五把枪和一箱手雷

| 武器 | 特点 | 价格 |
| --- | --- | --- |
| 手枪 | 起手武器，**备弹无限**，弹尽时永远退回它 | — |
| 霰弹枪 | 八发扇形，贴脸清场，击退最强 | $260 |
| 冲锋枪 | 射速最快，弹夹 40 发 | $420 |
| 突击步枪 | 高伤，**穿透三个目标**，尸群排队时最划算 | $640 |
| 火箭筒 | 一发一装填，直接炸出一个坑，**爆炸也会伤到自己** | $980 |

手雷同理：伤害高、范围大、离自己太近一样会疼。

场上八个红油桶是可引爆的，把僵尸引到桶边打一枪比什么枪都便宜。

## 波次与商店

每波清空后进商店，钱来自击杀和清波奖励。八个格子：弹药补给、医疗包、火力强化、战术靴、枪械保养、防弹衣、手雷、以及解锁下一把枪。数字键买，`ENTER` 开下一波，手机点卡片。

属性类的强化可以反复买，价格逐次上涨；每波清空还白送一颗手雷。

杀敌会掉落弹药箱、医疗包和手雷，走近自动吸过来 —— 闪烁就是快消失了。

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 全部内容，游戏逻辑在里面的 `<script>` 中 |
| `tools/` | 无头测试，不参与运行，部署时可以不带 |

没有构建步骤，改完直接刷新。本地预览双击 `index.html` 即可。想让同一 Wi-Fi 下的手机访问：

```bash
python3 -m http.server 8000
```

然后手机浏览器打开 `http://<你的内网IP>:8000/zombie/`。

## 无头测试

改完数值别只靠手感，跑一遍：

```bash
node tools/test.js          # 全部跑一遍
node tools/fuzz.js          # 随机乱按 12 分钟，查异常、NaN 和只进不出的数组
node tools/playtest.js      # 让机器人从第 1 波打到死，打印每波耗时和剩血
```

`playtest.js` 里的机器人比真人笨得多（只盯最近的一只、不留手雷给尸王），所以它撑到第几波不代表通关难度，而是**难度曲线的下限**：它现在稳定死在第 7～10 波。如果它一两波就死，说明前期太难；如果它躺着能打二十五波，说明数值太松；两种情况脚本都会直接报错。

它还盯着一件容易被忽略的事：**有没有哪一波打不完**。僵尸不会寻路，只要有一只被地形永久卡住，这一波就永远结束不了 —— 任何一波超过两分半，脚本会把剩下的僵尸位置打出来并失败。

画布调用在测试里全是打桩的，所以画错位置、图层顺序反了这类问题查不出来，那个只能靠真浏览器看。
