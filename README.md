# 飛簷 · 屋顶轻功

三更天的武侠屋顶跑酷，3D。单文件、零依赖、零外部请求：**没有 three.js**，渲染器是文件里自己写的一套 WebGL；整座城、每一片瓦、每一个人都是代码现场生成的多面体；音乐和音效由 Web Audio 实时合成。仓库里没有任何模型、贴图或音频素材。

## 玩法

| 按键 | 作用 |
| --- | --- |
| `W` `A` `S` `D` | 奔行（方向相对镜头） |
| `鼠标` | 转视角（先点一下画面锁定指针） |
| `Shift` | 疾奔 |
| `空格` | 起跳；**空中再点一次＝踏空**（二段跳，耗气） |
| 朝墙跑＋空中 | **壁走**，贴着墙面横跑一段；此时按跳＝蹬墙 |
| `Ctrl` / `C` | 地面滑铲；**空中按＝一记向前的踏空冲刺** |
| 鼠标左键 / `J` | 拔剑，连点接三段（第三段伤害翻倍并前冲） |
| `P` | 暂停　`R` 重来本回 |

**别落到地上。** 掉进街里就是失足，扣一条命，从最近踩过的屋顶重来；命耗光就结束。

左上角两条：红的是命（5 条），青的是**气**——踏空和壁走都吃气，站在实地上回得最快。

手机横屏会出现虚拟手柄：左边摇杆（推到底＝疾奔），右边 `跃` `斩` `纵`，**右半屏拖动转视角**。

## 三回

| 回 | 场景 | 终点 |
| --- | --- | --- |
| 一 | 夜巷 | 城北钟楼，撞钟 |
| 二 | 长街 | 同上，路更长、跳更远、弓手更多 |
| 三 | 皇城 | 钟亭上有**大内总管·裴九**，不打赢撞不了钟 |

路上会遇到：

- **刀客** —— 看见你就扑上来，两刀砍死
- **弓手** —— 隔三十步瞄准放箭，会预判你的走向
- **裴九** —— 掌风、冲刺劈砍、跳起震地三招循环；血过半换招，出手更快。震地那下**跳起来就躲得掉**

地形除了瓦顶，还有七种特殊路段：

| 路段 | 怎么过 |
| --- | --- |
| **木板桥** | 窄，没什么好说的，跑过去 |
| **木桩** | 一根一根点过去，桩顶只有一米半见方 |
| **城墙** | 难得能放开跑的一段 |
| **朽木台** | 落地约半秒后塌，别停 |
| **吊索** | 空中掠过就自动挂上，顺坡越滑越快；到头自动松手，中途按跳＝提前脱手带着速度飞出去 |
| **竹跳板** | 横向铺满出檐口，跑过去必然踩到，弹起近八米——对面那座楼平时上不去 |
| **水缸** | 能踩上去垫高，能推着走，也能推下屋顶摔个粉碎；推着撞人，人跟着一起下去 |

跨屋顶的空中常常挂着一串铜钱，绕路去接是划算的；偶尔有酒葫芦，回一条命。

每回按用时评甲乙丙等。标题页的城是活的，可以先看两眼再起纵。

## 做了什么

屋顶不是平台，是**曲面**。中式坡屋顶的飞檐起翘由一条曲线定义，画面和碰撞用的是**同一个函数**——你看见瓦面怎么翘，脚下就怎么翘，跑到檐口会被那道上翘轻轻托一下。

一座城 300 多栋房子按到主路线的距离分三档精度生成，近处有斗拱、格窗（窗纸是亮的）、檐角灯笼、正脊上的脊兽，远处只留轮廓。夜空、月亮、星、银河和地平线上两层城郭剪影全部在片元着色器里按视线方向算出来，没有天空盒贴图。

## 测试

游戏逻辑能在 Node 里跑（`tools/env.js` 用假的 DOM 和假的 WebGL 把 `index.html` 装载起来），所以改完关卡生成器不用手动跑图：

```bash
node tools/test.js        # 全部检查
node tools/mechanics.js   # 吊索、跳板、水缸逐条断言
node tools/playtest.js    # 让机器人把三回跑通
node tools/fuzz.js        # 26000 帧随机乱按
```

`playtest` 里的机器人很笨——只会朝下一个路点冲、前方没地就起跳、要掉下去了补一次踏空。**它跑得通，人就一定跑得通**；如果它在同一个路点反复摔（输出里会标「热点」），多半是生成器造出了跳不过去的距离。`mechanics` 补的是另一个洞：机器人绕过某个机制照样能通关，所以那三样得单独把主角摆到该触发的位置去断言。`fuzz` 盯的是异常和 NaN——物理里只要有一处除零，NaN 会顺着矩阵扩散到整个画面，肉眼极难定位。

两个脚本都用退出码表示成败，可以直接挂 CI。**注意：着色器编译在这套环境里是打桩的，GLSL 的语法错误查不出来**，那个只能靠真浏览器。

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 全部内容，游戏在里面的 `<script>` 中 |
| `tools/` | 无头测试，不参与运行，部署时可以不带 |

没有构建步骤，改完直接刷新。本地预览双击 `index.html` 即可。想让同一 Wi-Fi 下的手机访问：

```bash
python3 -m http.server 8000
```

然后手机浏览器打开 `http://<你的内网IP>:8000/`。

需要浏览器支持 WebGL。
