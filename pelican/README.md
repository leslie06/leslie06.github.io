# 鹈鹕骑单车 · PELICAN RIDE

一只白鹈鹕骑着复古单车，沿海岸公路兜风。整个场景——鹈鹕、自行车、地形、海水、天空、贴图、动画——全部由代码生成，没有用到 SVG、2D Canvas、外部模型或预渲染动画。

线上：<https://leslie06.github.io/pelican/>

## 跑起来

`index.html` 一个文件，双击用现代浏览器打开即可，断网也能玩——Three.js（0.170.0 压缩版）、用到的四个后期处理模块和两个字体子集都已经内嵌在文件里，零外部请求。只要求浏览器支持 WebGL2。

换 three 版本或改字体子集时重新跑一次打包脚本，它只替换文件里标记之间的那两段，不动其余代码：

```sh
node tools/vendor.mjs
```

## 操作

| 键 | 作用 |
| --- | --- |
| `W` / `S` | 加速 / 减速（0–30 km/h） |
| `A` / `D` | 向左 / 向右变道 |
| `空格` | 停车 / 出发 |
| `B` / `F` | 按车铃 / 喂鱼 |
| `C`、`1`–`6` | 切换机位：跟随、侧拍、环绕、电影、航拍、鹈鹕视角 |
| `T` / `P` | 慢动作 / 暂停 |
| `M` / `H` | 声音 / 隐藏界面 |

拖动转视角，滚轮或双指缩放。点鹈鹕它会叫一声，点车铃会响，点车筐会喂一条鱼。手机上界面会变成底部面板，画面中心自动上移。

## 骑行是怎么算的

- **传动**：牙盘 38 齿、飞轮 16 齿。踏频由车速按齿比推出来，16 km/h 约 54 rpm；链条一节一节沿牙盘与飞轮之间的真实公切线路径移动。
- **飞轮**：滑行时踏板停在水平位置，能听到棘爪的哒哒声（声音由 Web Audio 实时合成）；停车前会倒踩把一侧踏板转到起步位置，另一只脚落地，车身跟着倾斜。
- **腿和翅膀**：两段式 IK。脚掌锁在踏板上，翅膀握住车把并随转向移动；腿长按车架尺寸自动计算，踩到最低点时膝盖仍微屈。
- **身体**：骨盆随踩踏摆动，转弯按向心力侧倾，前轮绕真实转向轴转动；头部像真鸟一样做稳定补偿——身体晃动时头几乎不动，并始终保持水平。

## 文件结构

单文件，按段落分块：内嵌的 three.js（`//@@VENDOR_START@@` 到 `//@@VENDOR_END@@`，自动生成）→ 材质与程序化贴图 → 自行车 → 鹈鹕 → 世界（地形 / 海水 / 植被 / 天空）→ 骑行模拟 → 摄像机 → 声音与界面。

调试入口：控制台里 `pelican.advance(3)` 可以快进三秒模拟，`pelican.setTod(80)` 调时间，`pelican.setCam('side')` 换机位。
