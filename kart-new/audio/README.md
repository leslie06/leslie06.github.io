# 音效

文件名和用途在 `src/audio/SoundDefs.ts` 的表里（`file` 字段），比如 `engine-loop.webm`、
`boost.webm`、`item-hit.webm`。

**一个文件都不放也能出声**：`src/audio/synth.ts` 会现场合成一份占位音，
接口和真文件完全一样。放进来一个就自动换掉一个，代码不用动。

格式建议 `.webm`（Opus），移动端体积和解码都最划算。循环音（引擎、漂移摩擦、蓄力）
要剪成首尾能接上的一段，不然每循环一次会"啪"一声。

引擎声是用 `playbackRate` 拉音高跟着速度走的（0.75 ~ 2.35 倍），所以录/做的时候
基频要低一点，拉高之后才不刺耳。
