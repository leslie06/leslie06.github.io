# 合金小队 · METAL SQUAD

魂斗罗风格的横版跑射游戏。单文件、零依赖、零外部请求：画面全部用 Canvas 手绘，音乐音效由 Web Audio 实时合成，仓库里没有任何图片或音频素材。

**在线试玩：** https://leslie06.github.io/contra/

## 玩法

| 按键 | 作用 |
| --- | --- |
| `←` `→` | 移动 |
| `↑` `↓` | 瞄准（八方向：平射 / 斜上 / 朝上 / 空中斜下 / 朝下） |
| `↓` | 站在地面时卧倒 |
| `J` `Z` | 射击（按住连发） |
| `K` `SPACE` | 跳跃，松手更早则跳得更矮 |
| `↓` + 跳 | 从单向平台落下 |
| `P` | 暂停 |
| `R` | 重来 |

打开后**先点一下画面**，键盘和声音才会生效。

手机上会出现虚拟手柄：左边八方向键，右边 `B` 射击、`A` 跳跃。**推荐横屏玩。**

- **横屏** —— 画面铺满整屏，手柄半透明浮在画面上。屏幕比 16:9 更宽时手柄优先占两侧黑边，剩下的部分压在画面底部那条纯土层上（地面线以下没有玩法内容），实测只遮住玩法区的 1%～2%
- **竖屏** —— 画面在上、手柄贴底，完全不与画面重叠

碰到子弹或敌人**一下就死**，共 3 条命，死后原地复活并退回步枪。

## 内容

三关，各有一个头目：

| 关卡 | 场景 | 头目 |
| --- | --- | --- |
| 1 | 丛林登陆 | 要塞闸门 —— 打掉墙上两座炮塔 |
| 2 | 雪原突围 | 武装直升机 —— 投弹、散射、点名三段循环 |
| 3 | 钢铁要塞 | 中枢核心 —— 先打碎三颗护卫球才能伤到本体 |

空中会飞过补给舱，打爆它掉落武器：

| 字母 | 武器 | 特点 |
| --- | --- | --- |
| `M` | 机枪 | 射速最快 |
| `S` | 散弹 | 五发扇形，清场最强 |
| `L` | 激光 | 高伤穿透，同屏只有 4 发 |
| `F` | 火焰 | 双发螺旋弹，伤害 2 |
| `B` | 护盾 | 十秒无敌 |

敌人有跑兵、跳兵、蹲射兵、高台狙击手、无人机和地面炮台；地形有深坑、高台、可穿越的单向平台。

秘技：标题画面输入 `↑↑↓↓←→←→BA`，30 条命起步，并直接拿到散弹。

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 全部内容，游戏逻辑在里面的 `<script>` 中 |

没有构建步骤，改完直接刷新。本地预览双击 `index.html` 即可。想让同一 Wi-Fi 下的手机访问：

```bash
python3 -m http.server 8000
```

然后手机浏览器打开 `http://<你的内网IP>:8000/`。
