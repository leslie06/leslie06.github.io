# b城追车

GTA 式的开放世界游戏，场景是北京城中心：从天安门、故宫、前门到国贸 CBD，南到天坛。街道、楼房、树和路灯都来自 OpenStreetMap 真实数据。three.js 渲染，Rapier 做物理，TypeScript + Vite 构建。

完整设计方案（地图片区、城市数据管线、玩法、预算、里程碑）：https://claude.ai/code/artifact/f84d740e-9e09-4de4-8d47-41c433772ad6

## 当前进度

- **M0 车辆手感**：已验收。严格的手感评审子代理打了 7.0 分，验收线是 7 分。
- **M1–M2 城市和交通**：城市按 256 米一块在后台线程里流式加载。有 13 座程序化建模的地标：天安门、正阳门和箭楼、午门、太和殿、祈年殿、圜丘、皇穹宇、人民英雄纪念碑、北京站、国贸三期、中信大厦（中国尊）和央视大楼。车流靠右行驶、看红绿灯，还会给行人让路。
- **M3 下车**：随时下车走路，也能把路上任何一辆车抢过来开。人行道上有行人，会过马路、躲车，被车撞了会倒地。
- **M4 玩法**：出租车拉活、通缉和警察、街头赛车、车损和生命值。
- **画面**：真实天空和昼夜变化，路灯和窗户夜里会亮。有阵雨，雨后路面发亮有积水。还有级联阴影、环境光遮蔽、动态模糊、泛光和 AgX 调色。在 M2 Pro 上高画质约 12 毫秒一帧，稳定 60 帧。

开局是长安街东段（建国门外大街）上的一辆北京出租车。`?world=yard` 可以回到 M0 的驾校训练场。

## 手机

用手机浏览器打开就能玩，会自动出现触摸操作，画质自动降到低档：

- 左半屏按住拖动是方向盘，松手回正。
- 右下角是油门、刹车、手刹、上下车、视角。走路时换成跑、跳、上车、推人。
- 右半屏空白处拖动转视角。
- 左上角是暂停和地图。
- 横屏玩更舒服，竖屏时屏幕上方会提示。

`?touch=1` 可以在电脑上强制打开触摸界面，`?touch=0` 关掉。

## 玩法

- **出租车拉活**：开出租车时，附近会有人在路边招手，地图和街上会有蓝色光圈标出位置。停到乘客旁边，他会走过来上车，然后说要去哪儿，比如"师傅，去王府井"。目的地是地标或者真实的街道，跟着导航开过去，停进黄色光圈。车费按北京出租车计价：3 公里内 13 元，之后每公里 2.3 元。开得快有奖励，撞车扣小费，超时乘客会自己下车。钱会存下来。
- **通缉和警察**：撞人、抢车、撞警车会被通缉，右上角亮星，最多 5 颗。警车会追你、别你、围住你，停车超过两秒就被捕。三星以上前方会设路障。甩掉警察的办法是开出他们的视线，再离开地图上的搜索圈，过一会儿星星就会消失。
- **街头赛车**：路上有红色光圈标出的起点，一共 4 个，分别在建国门外大街、东三环中路、崇文门外大街和广渠门内大街。停进光圈，倒数 3、2、1 以后和三辆车比赛，全程约 2.4 公里，途经 8 个检查点，路上照常有车流。前三名分别拿 300、120、50 元。
- **车损**：车挺抗撞的，轻碰不掉血，一次碰撞只算一次。撞狠了车头先冒烟，然后动力下降，撞到彻底报废也还能慢慢挪，可以开去找下一辆车。
- **生命值**：走路时被车撞会掉血，一段时间后回到一半。血掉光就"死亡"，醒来在协和医院门口，扣医药费。
- **天气**：每隔一段时间会下一阵雨。

漂移技巧：
- **起漂**：进弯前拉一下手刹，然后按住油门和方向，车会稳定地横着过弯。
- **收车**：把方向回正就能收回来，按着油门也行；往反方向打收得更快。
- **原地甩尾**：停着的时候按住 W 和方向键，车会原地转圈；W+S 先烧胎再打方向也行。
- **高速**：键盘按住方向时车会稳稳地过弯，不会突然甩尾；想在高速上横过来，还是得拉手刹。

## 开发

```bash
npm install --legacy-peer-deps   # npm 10 的依赖解析器在 vitest 的可选依赖上会崩
npx vite --port 5195             # http://127.0.0.1:5195
npx tsc --noEmit
npx vitest run                   # 操控验收测试等，操控结果写进 .scratch/handling-report.txt
node scripts/shot.mjs --world city --poses all --out shots/r1 --hud   # 无头截图（城市）
node scripts/shot.mjs --world yard --poses all --out shots/yard      # 驾校训练场的截图
node .scratch/m4probe.mjs        # 无头跑一遍拉活、被捕、甩警察、发动机报废、死亡复活、赛车
```

URL 参数：
- 画面：`?quality=low|medium|high` 画质，`?lang=zh|en` 语言，`?tod=21.5` 固定时间，`?rain=0.8` 固定下雨。
- 场景：`?world=yard` 驾校训练场，`?notraffic` 不要车流，`?nopeople` 不要行人。
- 测试：`?wanted=3` 开局就有通缉。
- 调试：`?diag=1` 打开诊断面板，`?fps=0` 解除 60 帧上限。

架构、测试工具和踩过的坑见 [CLAUDE.md](CLAUDE.md)。

## 手感怎么验证的

`src/vehicle/Handling.test.ts` 在 Node 里直接跑真实的车辆物理和输入滤波，不开浏览器，整套不到 1 秒。它量出这些项目，每项都有通过线：
- 0-100 加速和 100-0 刹车距离
- 绕圈横向 g 值和手刹掉头
- 8 字漂移，分手柄式和键盘式两种驾驶员
- 飞坡落地、坡道驻车、翻车自救、倒车和烧胎

改任何车辆参数后跑一遍，就知道手感有没有退步。

另外有一个严格的"手感评审"子代理，按 GTA 式街机手感打分。第一轮打了 5.5 分，指出了五个问题，现在都已修好，各自有回归测试守着：
- 高速按住方向会突然甩尾
- 漂移收不回来
- 键盘点按只有全有、全无两档
- 假打滑冒烟
- 不能原地甩尾

第二轮打了 7.0 分，通过验收。
